# Mohamed Aladwash — Portfolio

```
portfolio-source/
├── index.html              ← الصفحة والمحتوى (النصوص، الأقسام)
├── css/style.css           ← كل التصميم والألوان (الألوان في أول الملف)
├── js/projects-links.js    ← حط هنا لينكات المشاريع
├── js/main.js              ← التنقل بين الأقسام وعمل أزرار اللينكات (مش محتاج تعدّل فيه)
└── assets/photo.jpg        ← صورتك (استبدلها بنفس الاسم)
```

## التشغيل
افتح `index.html` في المتصفح مباشرة.

## النشر المجاني على GitHub Pages
1. اعمل repository جديد على GitHub.
2. ارفع كل محتويات الفولدر (index.html + css + js + assets).
3. Settings → Pages → اختار branch `main` والفولدر `/ (root)` → Save.
4. هيظهر لك رابط زي `https://moadwsh.github.io/اسم-الريبو/`

## اللي بتعدّله فين
| عايز تغيّر | افتح |
|---|---|
| ألوان الموقع | `css/style.css` ← القسم 1 COLORS |
| نص أو تجربة أو مشروع | `index.html` |
| لينك مشروع | `js/projects-links.js` |
| الصورة | `assets/photo.jpg` |
